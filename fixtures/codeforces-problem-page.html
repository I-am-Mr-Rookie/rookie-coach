A. Synthetic Sum
time limit per test
1 second
memory limit per test
256 megabytes
input
standard input
output
standard output

You are given $$$n$$$ integers $$$a_1, a_2, \ldots, a_n$$$. Print their sum modulo $$$10^9+7$$$.

See the blog and the picture:

  • First rule with YES.
  • Second rule.
$$$$$$\sum_{i=1}^{n} a_i$$$$$$
Input

The first line contains $$$t$$$ ($$$1 \le t \le 100$$$).

Output

For each test case, print one integer.

Example
Input
Copy
2
3
1 2 3
Output
Copy
6
Input
1
5
Output
5
Note

In the first test, $$$1+2+3=6$$$.
