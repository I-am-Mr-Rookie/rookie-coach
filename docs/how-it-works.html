1. The flow

All the work happens inside your own Codeforces tab, using your normal signed-in session. The popup only starts it, so you can close the popup; keep the tab open.

2. Safety rules the collector follows

These are enforced in packages/codeforces/src/collect.ts and covered by tests.

1
One request every 2 seconds, the pace Codeforces sets for its API. About 10–15 minutes for 250 submissions.
progress panel shows time left
2
Code is read only for your own signed-in account. Another handle gets problems and verdicts only.
noted in the file
3
If Codeforces shows its "browser is being checked" page or refuses requests, the run stops and saves what it has. It never tries to get past the check.
reason written to Collection notes
4
A page that times out (for example a 504) is retried once after 5 seconds; after several failures in a row the remaining pages are skipped.
each gap is labelled in the file
5
Stop and save what I have ends the run early and still downloads the file.
button on the page
6
Nothing is stored except the one download. No key, secret, cookie, real name or city is written to the file.
checked by tests
