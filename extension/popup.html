Rookie Coach

Saves your Codeforces problems, statements, example tests, verdicts and code as one Markdown file for an AI coach or judge.

Open Codeforces in this tab and sign in, then click the extension again.

Backup: use an API key instead (experimental)

Only if reading your submission pages fails. Create a key in Codeforces settings, API. The key is used once and is never saved or written to the file.

About 2 seconds per page, so 250 submissions take roughly 10–15 minutes. Keep the Codeforces tab open; you can close this popup.
